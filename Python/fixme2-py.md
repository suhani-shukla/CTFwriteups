# fixme2.py

## Challenge

Fix the syntax error in this Python script to print the flag.

## Hints

1. Are equality and assignment the same symbol?
2. To view the file in the webshell, use `nano fixme2.py`.
3. To exit `nano`, press `Ctrl+X` and follow the prompts.
4. The `str_xor` function does not need to be reverse engineered for this challenge.

## Solution

1. Open the file and inspect the syntax.

   ```bash
   nano fixme2.py
   ```

1. Replace the assignment operator with the equality operator in the condition.

1. Run the script again.

   ```bash
   python fixme2.py
   ```
